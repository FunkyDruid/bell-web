# Bell (web)

Playable tubular bells and other struck bells in the browser. It uses a modal synthesis engine: each key is its own bell, a bank of resonating partials at the ratios measured on real instruments.

You can play it in three ways:
- the on-screen keys
- your computer keyboard: the letters are drawn on the keys, Space is the sustain pedal, and W / X shift the octave
- a MIDI keyboard, in Chrome or Edge

The page is plain static files with no build step.
